# 體質問卷 lead → Google 試算表

目的：訪客在體質問卷結果頁填完姓名／Email／電話，資料自動寫入你的 Google 試算表，
同一秒就在網頁上解鎖完整報告。你不用再逐個 WhatsApp 發報告。

設定一次就夠，之後不用再管。約 10 分鐘。

---

## 1. 開一張試算表

去 [sheets.new](https://sheets.new) 開一張新的 Google 試算表，改個名，例如
「體質問卷登記」。工作表分頁不用自己建，程式會自動開一張叫 `Leads` 的並加好標題列。

## 2. 貼上程式碼

在那張試算表裡：**擴充功能 → Apps Script**。

編輯器會有一個 `Code.gs`，裡面預設幾行 `function myFunction() {}`。
全選刪走，把本資料夾 `lead-sheet.gs` 的**全部內容**貼進去，按儲存（💾）。

想每收到一筆就有電郵通知的話，把最上面的

```js
var NOTIFY_EMAIL = '';
```

改成

```js
var NOTIFY_EMAIL = 'coolicesan1108@gmail.com';
```

不填就只寫入試算表，不寄信。

## 3. 部署成網頁應用程式

右上角 **部署 → 新增部署作業**：

| 欄位 | 選 |
| --- | --- |
| 類型（齒輪圖示） | **網頁應用程式** |
| 說明 | 隨便，例如 `體質問卷 lead` |
| 執行身分 | **我（你的 Google 帳號）** |
| 誰可以存取 | **所有人** ← 一定要揀這個 |

「所有人」指的是**任何人都可以送資料入你的試算表**，不是任何人都看得到試算表。
試算表本身仍然只有你打得開。

按 **部署** → 會彈出授權畫面 → 選你的帳號 → 「Google 尚未驗證這個應用程式」→
**進階 → 前往「（你的專案名稱）」（不安全）** → **允許**。
這是你自己寫給自己用的腳本，正常流程。

完成後複製那條**網頁應用程式網址**，形如：

```
https://script.google.com/macros/s/AKfycb....../exec
```

## 4. 貼入網站

打開專案根目錄的 `lead-capture.js`，找到最頂的 `SETUP`：

```js
  var SETUP = {
    // 貼上 Apps Script 的 /exec 網址。留空 = 使用 WhatsApp 退回模式。
    endpoint: '',
```

把網址貼進去：

```js
    endpoint: 'https://script.google.com/macros/s/AKfycb....../exec',
```

存檔、部署網站。搞掂。

## 5. 試一次

1. 用手機或無痕視窗開 `constitution.html`，做完問卷。
   （之前在同一部機填過的話，`localStorage` 記住了會直接放行 —— 用無痕視窗測試。）
2. 在「解鎖完整報告」填名同 Email，按送出。
3. 應該**即刻**變成「你的報告已準備好 → 開啟完整報告」，全程不經 WhatsApp。
4. 回試算表看，`Leads` 分頁應該多了一行。
5. 再開一個新的無痕視窗，直接打 `constitution-report.html?const=氣虛質`——
   應該被「請先完成問卷」擋住，證明個閘有效。

沒出現新的一行的話，見下面「出問題時」。

---

## 你自己預覽報告的網址

報告頁而家真係鎖住了：未留過聯絡資料就連內容都不會畫出來（以前的 `?k=cq`、
`?admin=1` 兩條後門已經拿走）。你自己想睇報告，用呢條網址，**加入書籤**：

```
https://katewoo.com/constitution-report.html?pv=ee9a93e3d2accfd5
```

- 不帶 `?const=` 就會出現體質選擇列，九種報告可以逐個揀來看。
- 想直接開某一種：`...?const=氣虛質&pv=ee9a93e3d2accfd5`
- 試算表每一行的「報告連結」都已經自動帶住呢條密鑰，撳落去就開得到訪客那一份。

**呢條網址等於一條後門**，傳咗俾邊個，嗰個人就不用填表也看得到報告。要換密鑰，
改兩處，兩邊必須一模一樣：

1. `lead-capture.js` 的 `SETUP.previewKey`
2. `google-apps-script/lead-sheet.gs` 的 `PREVIEW_KEY`（改完記得重新部署）

## 日後改動

改咗 `lead-sheet.gs` 之後要**重新部署**才生效，而且要用同一條網址：
**部署 → 管理部署作業 → 鉛筆圖示 → 版本：新版本 → 部署**。

按「新增部署作業」會產生**另一條**網址，舊網址仍然行舊版本 —— 唔好撳錯。

## 出問題時

**試算表無新行**
在 Apps Script 編輯器左邊揀「執行項目」，看有沒有 `doPost` 的紀錄同錯誤訊息。
完全沒有紀錄 = 請求根本到不了，多數是「誰可以存取」不是「所有人」，
或者貼錯網址（結尾一定是 `/exec`，不是 `/dev`）。

**訪客見到「送出時遇到問題」**
網站在送出失敗時會退回 WhatsApp 連結，lead 不會白白流失，但代表 endpoint 有問題，
照上一段查。

**同一個人出現兩行**
正常情況不會 —— 每筆帶著 `lead_id`，重送會被 `hasLeadId()` 擋住。
真的出現的話，代表對方自己填了兩次。

## 私隱

寫入試算表的只有：姓名、電話、Email、評估得出的體質類型、語言、是否同意收健康資訊。
**問卷的逐題答案不會上載**，網站上的私隱聲明就是這樣寫的，改動程式時要保持一致。
